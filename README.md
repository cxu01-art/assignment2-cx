# assignment2-cx

## Dataset:
The assignment used the penguins.csv dataset that contains information about penguins, including their species, island, physical measurements, sex, and year.

## Data Analysis Script:
The penguins_analysis.R conducted two descriptive analyses.
1. Descriptive Statistics: Uses summary() to calculate summary statistics for the dataset.
2. Species Counts: Uses table() to count the number of penguins in each species.
The results are saved in penguins_results.txt

## How to reproduce the analysis.
1. Download or clone this repository.
2. Open RStudio
3. Set the working directory to the repository folder containing penguins.csv
4. Open penguins_analysis.R
5. Click Source to run the entire script.
6. Open penguins_results.txt to view the results.
